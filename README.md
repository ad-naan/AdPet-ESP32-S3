# AdPet - ESP32-S3 SuperMini Desktop Pet
> An open source miniature interactive desktop pet running on ESP32-S3 SuperMini, supporting screen animation, expression switching and expandable interactive functions.

## Features
- Dynamic facial expression & sprite animation
- Small form factor based on ESP32-S3 SuperMini
- Extensible: WiFi sync, ambient light sensing, button interaction
- Easy to compile via PlatformIO / Arduino IDE
- Fully customizable character assets

## Hardware List
- Mainboard: ESP32-S3 SuperMini
- Optional: SPI/OLED screen, tactile buttons, small speaker

## Quick Start
1. `git clone https://github.com/ad-naan/AdPet-ESP32-S3.git`
2. Import project with PlatformIO or Arduino IDE
3. Select corresponding board and compile firmware
4. Flash firmware to ESP32-S3 SuperMini
